## ✍ 프로젝트 개요

내눈 키오스크+는 안과 검진 및 바이탈 측정을 통합한 키오스크 솔루션입니다.

사용자가 직접 시력, 황반변성, 사시, 노안조절력 등 다양한 안과 검사를 수행하고,

혈압, 악력, 치매 검사 등 바이탈 측정까지 가능한 통합 검진 플랫폼입니다.

### 기획의도

실버계층의 건강 관리 접근성 향상

- 병원 방문 없이 간편한 자가 검진

- 다양한 안과 검사 및 바이탈 측정 통합

- 직관적인 UI/UX로 누구나 쉽게 사용 가능

- 검사 결과 즉시 확인 및 프린터 출력

### 서비스 소개

- 개발 기간: 2025.10 ~ 2025.11

- 팀원: 6명

- 서비스 개요: [안과 검진 및 바이탈 통합 키오스크 솔루션] 내눈 키오스크+

- 주요 특징: 얼굴 인식 로그인, 음성 안내(TTS/STT), 프린터 연동, 다국어 지원

## 📦 설치 및 실행

### 사전 요구사항

- Android Studio
- JDK 17 이상
- Android SDK 26 이상
- Gradle 8.0 이상

### SDK 설치

실행을 위해 외부 SDK 파일이 필요합니다.

1. `app` 폴더 안에 `libs` 폴더 생성 (이미 존재하는 경우 생략)

2. 다음 SDK 파일을 다운로드하여 `libs` 폴더에 넣기:
   - `NemonicSdk.aar` (신형 프린터)
   - `nemonic.aar` (구형 프린터, 선택사항)
   - `BPBIO_SDK.jar` (혈압계 연동)
   - `gson-2.7.jar`

3. 다운로드 주소: https://drive.google.com/drive/folders/1cxR8F50x2aE3WhCYqViJyxyL838-3JIq?usp=sharing

### 빌드 및 실행

```bash
# 프로젝트 클론
git clone [repository-url]

# 프로젝트 디렉토리로 이동
cd Nenoon-Kiosk-dev-2

# Gradle 빌드
./gradlew build

# 앱 실행
./gradlew installDebug
```

### 주의사항

- SDK 파일이 없으면 빌드 오류가 발생할 수 있습니다.
- 프린터 SDK 둘 다 다운받으면 구형/신형 프린터 모두 동작합니다.
- Device 관리자 권한이 필요한 기능들이 있습니다.
